# 迭代文档导航

本目录按迭代归档「直播录制调度平台 + worker」各阶段的实现文档。规范遵循全局迭代文档规范，总设计见 [../architecture.md](../architecture.md)。

## 版本号规则

- V0.0.1 ~ V0.0.8：初始建设期（骨架 → 部署联调），发版测试六项门禁全过、已知问题修复闭环，**可发版**。
- V0.1.0 起：次版本递增 = 新功能板块（安全加固与配套对齐）。
- 状态：`⚪ 待开始` → `🟡 进行中` → `🟢 已上线`。

## 执行纪律

每个迭代的实现必须由用户下达命令后才开始；该迭代完成并通过验证后，停下来等用户确认，再进入下一个。
