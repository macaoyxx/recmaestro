## 2. MySQL 重启零丢失

**步骤**：`05-mysql-restart.sh`：登录一次后至快照 B 不做任何写操作 → 快照 A（6 表 COUNT/SUM(id)/MAX(id) + 任务分状态 + 节点行）→ restart → 等容器 health=healthy → 快照 B → diff。

## 6. 结论

- 三层存储（Redis AOF / MySQL 卷 / worker_records 卷）与调度状态机在单点重启与全栈重建下均自愈，且运行中录制与待派发任务零损失：Redis 重启对在录任务完全无感（对账产物覆盖全窗口），全栈重建中断任务按设计在 recover_window+tick 对齐后由原 node_id 无缝续录。
- 验收全部走「时长对账 + 下载 ffprobe 复核」口径，4 个产物（424.1/112.3/515.8s 及环境-1 74.0s）两口径一致。
- 无 Issue；1 条部署形态观察点（node_id 依赖 IP，多机部署需固定 NODE_ID 或保证 IP 稳定）已记录在 §3 供生产参考。
