## 8. 本轮踩坑记录（后续场景必读）

1. **`GET /api/tasks` 是 404**：任务列表是 `POST /api/tasks/list`（JSON 入参 `{"page":1,"page_size":N}`，V0.1.0 分页查询统一 POST，见 `internal/scheduler/server.go:107`）。
2. **任务 id 是雪花 ID 字符串**（如 `"2110556939766206464"`），不是数字——shell 里用 `"id":"[0-9]*"` 提取（带引号）。
3. **Windows→WSL 多层引号转义是坑**：复杂流程（含 JSON 构造/轮询）写成 .sh 文件再 `wsl bash <文件>` 执行，别在 `wsl -e bash -c "..."` 里硬嵌；本轮冒烟轮询失败一次即因引号转义（任务本身创建成功并跑完，无影响）。
4. **中文任务名**：命令行里用 JSON `\uXXXX` 转义（【环境-1】=`\u3010\u73af\u5883-1\u3011`）或走脚本文件，避免编码问题。
5. **登录连续失败 5 次锁号**（`internal/scheduler/handler_auth.go:16` maxFailedLoginAttempts=5），密码一律经 login.sh，别手搓。
6. worker 容器名/IP 对照（本次快照，重建后会变）：deploy-worker-1=172.21.0.5、deploy-worker-2=172.21.0.8、deploy-worker-3=172.21.0.7。
